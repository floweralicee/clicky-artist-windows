Clicky 是什么？
---------------
Clicky 是一个蓝色小助手，会出现在你的鼠标光标旁边。
你按住键盘上的几个键，对着屏幕提问，Clicky 就会用语音回答你——
还能把蓝色小点移到屏幕上的按钮和工具上，帮你指路。

适用于 Maya、After Effects、Blender、Premiere、DaVinci Resolve、
Toon Boom Harmony 等你日常使用的软件。


开始之前
--------
你需要：
  • Windows 10 或 Windows 11 电脑（64 位）
  • 能用的麦克风（笔记本自带麦克风就可以）
  • 网络连接（注册账号和获取 AI 回答需要联网）


第一步 — 下载并解压
-------------------
1. 打开 Clicky 网站：
     https://www.floweralice.me/clicky

2. 输入你的邮箱地址。

3. 点击「download windows」（下载 Windows 版）。
   浏览器会保存文件：clicky-windows-artists.zip

   直接下载链接（如果已经输入过邮箱）：
     https://www.floweralice.me/clicky/download/clicky-windows-artists.zip

4. 在「下载」文件夹里找到这个 zip 压缩包。

5. 右键点击 zip 文件 → 选择「全部解压缩」。

6. 打开解压后出现的  Clicky  文件夹。

7. 在 Clicky 文件夹里你应该能看到：
     Clicky.exe          ← 这就是应用程序
     HOW-TO-USE.txt      ← 英文版说明
     HOW-TO-USE-中文.txt ← 本文件（中文版）
     （还有其他支持文件——这是正常的）


第二步 — 第一次打开 Clicky
---------------------------
1. 双击 Clicky.exe。

2. 如果 Windows 弹出蓝色警告「Windows 已保护你的电脑」：
     • 点击「更多信息」
     • 点击「仍要运行」
   （这是正常的——这个应用不是从微软商店下载的。）

3. 如果 Windows 询问是否允许使用麦克风：
     • 点击「是」或「允许」
   Clicky 需要麦克风才能听到你说话。

4. 会出现注册窗口。
     • 点击「Get started」（开始）
     • 输入你的邮箱和密码
     • 点击「Create account」（创建账号）

   已有账号？点击「Already have an account? Sign in」（登录）


第三步 — Clicky 已在运行
-------------------------
登录成功后：

  • 鼠标光标旁边会出现一个蓝色小点。
  • 屏幕右下角会出现一个蓝色圆形图标
    （系统托盘——如果看不到，点击任务栏上的 ^ 箭头）。

Clicky 在后台运行，没有大的主窗口。
这是正常的。


第四步 — 向 Clicky 提问（最重要！）
------------------------------------
1. 打开你需要帮助的软件（Maya、After Effects 等）。

2. 同时按住这三个键：
     Ctrl  +  Alt  +  空格键（Space）
   （三个键一起按住，不要一个一个按。）

3. 按住的同时，清楚地说出你的问题。
   例如：
     「渲染设置按钮在哪里？」
     「怎么在这里加关键帧？」
     「这个面板是做什么的？」

4. 说完后松开所有键。

5. 等几秒钟。Clicky 会：
     • 读取你的屏幕
     • 思考你的问题
     • 用语音回答你
     • 把蓝色小点移到屏幕上的相关位置（有帮助时）


第五步 — 其他使用方式
---------------------
  • 大声说「Clicky」也可以唤醒它，然后再提问。
    （可以在托盘菜单里开关这个功能。）

  • 按 Esc 键可以停止 Clicky 正在说的话。

  • 如果 Clicky 给了分步说明，说「next」或「continue」
    可以进入下一步。

  • 说「repeat」可以重复听上一个回答。


第六步 — 小面板和托盘菜单
-------------------------
右键点击右下角的蓝色圆形图标（系统托盘）。

菜单里可以：
  • Show Panel / Hide Panel — 显示或隐藏状态小窗口
  • 查看还剩多少免费次数
  • Sign out — 退出登录
  • Quit — 完全关闭 Clicky

小面板会显示：
  「Listening…」  — Clicky 正在听你说话
  「Thinking…」   — Clicky 正在处理你的问题
  「Speaking…」   — Clicky 正在语音回答


免费次数和订阅
--------------
  • 注册后有 10 次免费使用机会。
  • 每次向 Clicky 提问算使用 1 次。
  • 免费次数用完后，Clicky 会显示订阅页面，
    每月 $10 美元（约 70 元人民币，以实际扣款为准）。
  • 点击「Subscribe — $10/month」在浏览器里完成付款。
  • 付款成功后，Clicky 会自动解锁无限次使用。


使用小贴士
----------
  • 说话清楚，问题尽量简短。
  • 确保你问的东西在屏幕上能看到。
  • 如果 Clicky 听到自己的声音，建议戴耳机。
  • 保持 Clicky 在运行——问完一个问题不用关闭它。
  • 如果蓝色小点消失了，检查托盘图标是否还在。


常见问题
--------

问题：看不到托盘图标
  → 点击屏幕右下角时钟旁边的 ^（向上箭头）。
  → 找蓝色小圆点图标。

问题：Clicky 听不到我说话
  → 打开 Windows 设置 → 隐私 → 麦克风
  → 开启「允许桌面应用访问你的麦克风」
  → 确认 Windows 声音设置里麦克风没有静音。

问题：打开时提示「Failed to load Python DLL」或无法启动
  → 先安装这个免费的微软组件，然后再试：
     https://aka.ms/vs/17/release/vc_redist.x64.exe
  → 如果还不行，从这里重新下载最新版：
     https://www.floweralice.me/clicky/download/clicky-windows-artists.zip

问题：注册或登录失败
  → 检查网络连接。
  → 等一分钟再试。
  → 密码至少 6 个字符。

问题：Clicky 说免费次数已用完
  → 在 Clicky 显示的页面上订阅 $10/月，
    或者如果已经订阅过，重新登录。

问题：Windows SmartScreen 拦截了应用
  → 点击「更多信息」→「仍要运行」
